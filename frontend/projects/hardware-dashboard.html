Hardware Dashboard

A hosted utility showing aggregate CPU, RAM, disk, and network metrics for the Ahlyx Labs backend host.

Status: Live utility

Last reviewed: 2026-09-17

Open tool →View source on GitHub →Browse projects →

Overview

Hardware Dashboard is a small public view of the lab's own backend telemetry. It is intended for visitors who want to see the current host's aggregate resource readings. A concrete use is opening the dashboard to view backend CPU, memory, disk, and network totals as the page refreshes.

What currently works

The current hosted implementation is backed by the Ahlyx Labs Go service and displays aggregate CPU, RAM, disk, network, and generic OS telemetry. It is distinct from the earlier local Python Hardware Dashboard project.

How it works

Ahlyx Labs backend host → Go hardware handlers → hosted dashboard → aggregate metric display

The browser requests only the published backend metrics. It does not inspect or collect data from the visitor's device.

Getting started

Open the hosted dashboard; no local agent or installation is required for the current public utility. Developers looking for the historical Python monitor should treat it as a separate local implementation, not the source of the current hosted service.

Security, privacy, and limitations

The dashboard reports aggregate telemetry for the lab's backend, not the visitor's computer. The current hosted implementation intentionally excludes sensitive host, interface, and filesystem inventories, so it is not a complete host-inspection utility or diagnostic agent.

References

The hosted behavior was checked against the maintained Ahlyx Labs hardware implementation (commit b3da861). The historical Python README (commit c3d6906) is included only for that distinction.
