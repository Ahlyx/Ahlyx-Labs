Network Scanner

A local Python tool for ARP host discovery and TCP scanning in authorized IPv4 lab networks, with flags for selected OT/ICS-associated ports.

Status: Local tool

Last reviewed: 2026-09-17

View source on GitHub →Browse projects →

Overview

Network Scanner supports local or authorized-lab inventory and port review. It is intended for a network owner or permitted tester who wants to discover hosts and note open TCP ports. A concrete use is running a scoped 192.168.1.0/24 scan in a lab and reviewing discovered host and OT/ICS-port flags.

What currently works

The maintained source provides Scapy ARP discovery, TCP port scanning, MAC vendor context, Rich CLI output, and a local FastAPI web dashboard. Its target validation accepts IPv4 lab targets up to /24; IPv6 and larger networks are rejected.

How it works

authorized IPv4 /24 target → ARP discovery → TCP scan → local CLI or dashboard results

Port association can flag a known OT/ICS port but does not prove a protocol, device type, ownership, or vulnerability.

Getting started

Use Linux with Python 3.12+, install requirements.txt, and use the required raw-socket privilege for ARP discovery. The local dashboard example binds Uvicorn to 127.0.0.1. The repository documents CLI and local web usage; there is no hosted public scanning endpoint.

Security, privacy, and limitations

Only scan networks you own or have explicit permission to assess. The tool has no Ahlyx Labs hosted scanner frontend: /scanner remains a redirect to the source repository. Do not expose its local API to a LAN or internet without a deliberate access-control design.
