/ Security and trust

Verify the channel before you trust the message.

Ahlyx Labs is public by design: the source, architecture, and security reasoning are available for review. This page identifies the real channels and the safe way to report a vulnerability or validate a message.

Official website

https://ahlyxlabs.com is the official Ahlyx Labs website.

Official GitHub

github.com/Ahlyx is the official source and project identity.

Official social channel

@AhIyxx is the currently published Ahlyx social channel.

Software releases

Download PCAP Agent only from the official GitHub Releases page. Verify the published checksums before running an archive.

Report a vulnerability

Send a concise report to alex@ahlyxlabs.com, or use the contact methods in security.txt. Do not include secrets in a public GitHub issue.

Ahlyx Labs will never ask through an unsolicited message for:
  • passwords or API keys;
  • MFA or recovery codes;
  • private keys.

If a message is suspicious, do not reply using the message's links or contact details. Independently use the website and contact information published here.
